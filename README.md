# 십이지 수학탐험대 (SmartVibe)

12지신 탐험대와 함께 악당을 물리치며 배우는 **4학년 1학기 스토리 모드 수학** 웹앱 모음이에요.
첫 화면(`index.html`)의 탐험 지도에서 **학년 → 학기 → 단원(섬) → 차시** 순서로 골라 시작해요.

## GitHub Pages로 올리기 (처음 한 번)
1. GitHub에서 새 저장소(Repository)를 만들어요. 예: `smartvibe-math` · **Public**
2. 이 폴더 안의 파일을 모두 저장소에 올려요. (**Add file → Upload files** 에 끌어다 놓기 → Commit)
3. 저장소 **Settings → Pages → Branch: `main` / `(root)` → Save**
4. 1~2분 뒤 `https://내아이디.github.io/smartvibe-math/` 주소로 열려요.

## 새 차시 올리기 (매번)
1. 새 차시 파일(예: `4-1-6-2-스토리모드.html`)을 저장소에 올려요.
2. 문제 상황 그림이 있으면 `assets/scenes/4-1-6-2.webp` 로 올려요. (카드 그림, 없어도 괜찮아요)
3. `lessons.js` 의 맨 아래에 한 줄을 추가해요.
   ```js
   [6, '2차시', '규칙을 찾아 식으로 나타내기', '4-1-6-2-스토리모드.html', 'tori', '#db2777', ['게임1', '게임2'], '2026-11-20'],
   ```
   마지막의 날짜를 쓰면 14일 동안 **NEW** 표시가 붙고, 첫 화면 「새로 올라온 탐험」에 나와요.

## 새 학년·학기 열기
`lessons.js` 의 `SV_COURSES` 에서 그 학기의 `units: []` 안에 단원 목록을 넣어요. (4학년 1학기 부분을 그대로 본떠 쓰면 돼요)
차시 파일 이름의 앞부분(예: `5-2-3-1-…`)으로 학년·학기가 저절로 정해지니, 파일 이름만 규칙대로 지으면 돼요.
학생에게 특정 학기를 바로 열어 주려면 주소 뒤에 `?course=5-2` 를 붙여요.

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 첫 화면 (탐험 지도 · 새로 올라온 탐험 · 선생님 코너) |
| `lessons.js` | 차시 목록 — 새 차시는 여기에 한 줄 추가 |
| `4-1-*-스토리모드.html` · `4-1-1-U-단원마무리.html` | 차시 앱 (파일 하나로 열려요) |
| `guide.html` · `apps-script/Code.gs` | 선생님용 학급 기록 설치 안내 · 구글 시트 코드 |
| `assets/hub` · `assets/scenes` | 캐릭터 그림 · 차시 카드 그림 |
| `assets/characters/` | 캐릭터 그림(PNG)을 넣는 곳 |

## 개인정보 · 보안
- 학생 정보는 **학번·이름**만 받아요.
- 선생님 비밀번호는 **Apps Script(구글 시트) 안에만** 적어요. `Code.gs`의 `여기에-비밀번호`는 그대로 두고 올려요. 이 저장소에 실제 비밀번호를 쓰지 마세요.
- 구글 시트는 **비공개**로 두세요. 학생 기록은 선생님 시트로만 모여요.
